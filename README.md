# Stage Fright — Landing Page

## Cómo abrirla
1. Descomprime el ZIP.
2. Abre la carpeta `StageFright_Web` desde Visual Studio Code (Archivo > Abrir carpeta).
3. Instala la extensión **Live Server** (si no la tienes).
4. Haz clic derecho en `index.html` > **Open with Live Server**.

El trailer está incluido en `assets/stage-fright-trailer.mp4` y las imágenes originales en `assets/`. No hay instalación de npm.

## Botón DOWNLOAD
El botón de la portada **NO enlaza a Steam**. Para habilitar una descarga real, guarda tu juego empaquetado como `downloads/StageFright.zip` (sin cambiar ese nombre). Si deseas otra ruta, cambia `href` del elemento `id="download"` en `index.html`. Mientras no exista, se mostrará un aviso.
